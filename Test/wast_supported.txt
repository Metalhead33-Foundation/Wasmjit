# ([.]) so it is still listed by --list-tests and can be run on demand, but stays
# out of the default run.
#
# Format: one script basename per line (no directory, no .wast extension).
# Blank lines and '#' comments are ignored. Updating this file does NOT require
# a rebuild.
#
# How to refresh it (see docs/TESTING.md for the full recipe):
#   1. WASM_SPEC_TIMEOUT=10 WASM_SPEC_SCRIPTS=all ./WasmJit '[spec]' 2>&1 | tee all.log
#   2. keep every script whose line reads  passed=<n> failed=0  with n > 0
#      and which was neither killed by a signal nor timed out.
